# 这个文件夹是什么

`参考原型-弧光镇晚间新闻.html` 是拆分重构前用来核对"原型已有哪些机制"的参考资料（一个已建好的完整 COC 播报向网页游戏，剧情叫《弧光镇晚间新闻》，是阴谋公司/恐怖题材，人物、地点、11 天的全部文案都是别的故事，**跟"雾岭镇"设定无关**）。

之所以留着它，只是因为它的引擎写法（时间推进、线索采集、复盘问答、播报/收听率结算、档案库正文关键词高亮）和 `游戏设计框架.md` 里描述的"已有原型"是同一类实现，重构 `engine/` 时参照过它的思路。

它**不是**本项目的交付内容，不会被 `index.html` 加载，删掉也不影响 `engine/` + `content/` + `assets/` 那套新结构运行。留着纯粹是怕以后想不起来某个机制当初是怎么抄的思路。
